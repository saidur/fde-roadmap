Objective
The goal of this assignment is to assess learners' ability to:

Use AI coding assistants for software development.

Compare outputs from different AI models.

Identify AI-generated code quality issues.

Detect AI hallucinations and incorrect assumptions.

Apply human judgment during AI-assisted development.
